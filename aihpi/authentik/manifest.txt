# Authentik patch manifest: <our copy> <upstream path>
#
# Each line pairs a fork copy in this directory with the upstream file it
# replaces at build time. baseline.sha256 records the hash and the git blob id
# of upstream's version at the time the copy was taken, so apply.sh can fail
# loudly when upstream moves on, and the merge workflow can 3-way merge our
# additions onto their new version using that blob as the merge base.
#
# Only files too intertwined to express as anchored patches belong here.
# Everything smaller lives in aihpi/branding/apply.sh instead, because a copy
# goes stale on any change to the file while a patch only trips when the lines
# it targets move.
